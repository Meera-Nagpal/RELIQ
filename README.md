# RELIQ

RELIQ is an AI evaluation and reliability platform for testing models, tracing regressions, and evaluating complex agent systems.

## Live Demo

🚀 **[Open RELIQ](https://reliq-id3mhh3q2-meera-nagpal.vercel.app)**

## Repository

This repository contains the RELIQ application, including the React/Vite frontend, Node/Express API, evaluation system, provider integrations, and SQLite-backed evaluation data layer.

> **Deployment note:** The current Vercel deployment uses runtime SQLite storage. Vercel's filesystem is ephemeral, so database persistence across instance replacement or redeployment is not guaranteed.
